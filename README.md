# 小兔叽勇者的视频作品集

手绘涂鸦风格的个人视频作品网站，使用 GitHub Pages 发布。

## 更新作品

1. 将嵌入作者水印、添加片尾的 MP4 放入 `videos/`。
2. 将封面放入 `assets/`。
3. 在 `works.json` 添加作品的标题、题材、简介、封面、视频路径、下载文件名、大小和时长。
4. 提交到 `main` 后，GitHub Pages 自动更新。

不要提交无水印原片。每个文件需小于 GitHub 的 100 MiB 限制。
作品增多后，可将媒体迁移到对象存储或视频服务；GitHub Releases 适合提供下载，不能保证直接作为播放器的视频来源。

## 本地预览

在此目录运行 `python -m http.server 8080`，打开 `http://localhost:8080`。
